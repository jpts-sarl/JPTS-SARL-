# JPTS SARL — Site Internet

Site vitrine statique, responsive et prêt à être mis en ligne.

## Contenu
- `index.html` : page principale
- `style.css` : design
- `assets/bureau-jpts.jpg` : photo fournie par le propriétaire
- `assets/realisation-jpts.mp4` : vidéo fournie par JPTS

## Mise en ligne
Le site peut être publié sur un hébergeur statique (par exemple GitHub Pages, Netlify ou un hébergement web classique). Il suffit d'envoyer tout le contenu du dossier en conservant la structure.

## À compléter avant publication
- Remplacer les trois visuels de tenues par les vraies photos des uniformes JPTS.
- Ajouter éventuellement le logo officiel en fichier image.
- Ajouter un nom de domaine, par exemple un domaine correspondant à JPTS SARL, après vérification de sa disponibilité.
